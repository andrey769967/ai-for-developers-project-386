# TypeSpec — источник контракта, сервер написан вручную

`contract/main.tsp` — единственный источник истины для API: из него генерируются OpenAPI и типы клиента. Эмиттера TypeSpec для Fastify не существует, поэтому серверные типы (`server/src/types.ts`) и маршруты написаны руками по контракту, а соответствие держится на тестах, а не на генерации.

## Consequences

- Соответствие сервера контракту не проверяется машиной: расхождения в кодах ответов и ошибках возможны и уже есть.
- Любое изменение контракта требует ручной синхронизации `server/src/types.ts`; забыть её ничто не мешает.
- Сгенерированные типы клиента описывают только то, что объявлено в контракте, поэтому неполный контракт напрямую ослабляет типизацию фронтенда.
